# SMARTPark UPB - Sistem de Monitorizare a Parcării

**Student:** Ilie Marian-Ionuț

**Grupa:** 633AB

**Disciplina:** Rețele Neuronale

## Descriere

Acest repository conține proiectul complet pentru disciplina Rețele Neuronale. Sistemul SMARTPark utilizează Computer Vision și Deep Learning pentru a monitoriza și clasifica în timp real locurile de parcare (Liber/Ocupat), folosind un dataset generat sintetic. Proiectul a evoluat de la o simplă clasificare la un asistent inteligent cu logică de proximitate și dashboard analitic.

## Structura Proiectului (Navigare Etape)

Proiectul este documentat incremental, conform cerințelor de laborator:

* [📘 Etapa 3: Analiza și Pregătirea Datelor](README_Etapa3.md) - Generarea dataset-ului sintetic și analiza EDA.
* [📘 Etapa 4: Arhitectura SIA](README_Etapa4.md) - Design-ul sistemului, modulele software și State Machine.
* [📘 Etapa 5: Antrenare și Evaluare](README_Etapa5.md) - Configurarea CNN, antrenarea pe date sintetice și rezultate baseline.
* [📘 Etapa 6: Optimizare și Concluzii](etapa6_optimizare_concluzii.md) - Analiza performanței, optimizarea modelului, robustețea la lumină și concluziile finale.

## Tehnologii Utilizate

* **Deep Learning:** PyTorch (CNN Custom).
* **Computer Vision:** OpenCV pentru procesare și simulare.
* **Interfață:** Streamlit (Enterprise Dark Theme).
* **Data Science:** Pandas, NumPy, Scikit-learn.
